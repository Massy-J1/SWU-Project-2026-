# 프로토타입 만들기
구상한 프로토타입은 다음과 같은 자료들로 만들어졌다.
DATASET : https://github.com/Ez-Sy01/KOR_phishing_Detect-Dataset
오픈소스 메시지 : https://github.com/FossifyOrg/Messages

스코어링 시스템으로 위험도를 평가하도록 메시지에 기본적으로 단계를 나눠두었다.
[안전(0 - 9점) : 연두색, 의심(10-19) : 노랑,경고(20-39) : 주황 ,위험(40~) : 빨강] 

### 경고 설정
스미싱의심 메시지에 각 단계에 따른 배경색을 적용하고, 메시지에 들어가면 5초동안 접근이 불가능하도록 경고를 띄운다. (1회 이후로는 사라지지만, 상단에 경고 배너는 뜬다.)

### 경고 조건
1. 메시지에 URL 이 포함되어있는지 정규식으로 확인 후 스코어에 10점을 올린다, 최종목표는 LLM 같은거나 로컬 LLM 붙여서 사이트 내용이나, 리다이렉트 여부 검사한 후에 의심단계로 올리는것이다.

2. TF-IDF 통해서 온 문장의 핵심 단어를 뽑아서 스미싱으로 의심되는 단어가 있다면 스코어를 추가하는방식으로 스코어 10점 올린다. (추후 데이터셋 추가 혹은 수집으로 정확도 향상을 기대중이다.)

### 추가 기능 및 구상
보이스피싱, 더치트등, 데이터셋을 찾아서 위험한 전화번호에서 오는 스미싱 메시지 필터링기능도 추가하는게 좋을거같다.

그 외에도 오늘 조금 조사해본 코사인유사도나 다른 기술들을 병합시켜보는 방안도 생각해보는게 좋겠다.
